# NextTech AI Support Bot v6.0.0

Release date: 2026-09-11

## Overview

v6.0.0 is the first fully packaged production-oriented release of the NextTech AI Support Bot. It brings together the customer chat experience, AI response pipeline, managed knowledge retrieval, human support handoff, WhatsApp integration, persistence, authentication, observability, CI, Docker deployment, and repository governance into one release-ready codebase.

## Highlights

- FastAPI customer support backend with browser Web Chat.
- Gemini response generation with configurable model and temperature.
- Structured intent propagation and deterministic action routing.
- BM25 knowledge retrieval across static JSON and managed database knowledge.
- Persistent conversations, messages, users, assignments, feedback, AI metrics, and audit events.
- Agent dashboard with queue, transcript, claim, reply, resolve, and bot-return workflows.
- WhatsApp webhook verification, signature checking, inbound text handling, and outbound delivery.
- JWT authentication with agent/admin roles and bcrypt password hashing.
- AI quality metrics and customer CSAT feedback.
- CRM and order-status integration hooks.
- Alembic migrations, Docker/Docker Compose, CI, health/readiness checks, and production deployment guidance.
- Repository maintenance layer with SECURITY.md, CONTRIBUTING.md, Dependabot, CODEOWNERS, and PR template.

## Upgrade / deployment notes

Before deploying this release:

1. Configure production secrets and integration credentials outside the repository.
2. Use PostgreSQL for production data.
3. Run `alembic upgrade head` before starting the new application version.
4. Build and deploy the Docker image or run the FastAPI application behind a production reverse proxy.
5. Verify `/health` and `/ready` after deployment.
6. Verify agent login, Web Chat, handoff, feedback, and any enabled external integrations.

See `docs/PRODUCTION.md` for the production checklist.

## Compatibility

- Python 3.12 is the CI target.
- PostgreSQL is the recommended production database.
- SQLite remains supported for local development and tests.

## Known environment-specific requirements

The codebase intentionally does not hard-code hosting, domain/TLS, database provider, secret manager, backup/alert destinations, Gemini credentials, WhatsApp credentials, or third-party CRM/order endpoints. These must be configured by the deployment environment.
